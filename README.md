# ALSRS
ALSRS (Agricultural Land Suitability Recommendation System)

## Databases
This folder conteins the databases generated in this project. 
* The databases are stored in CSV format.

## img/maps
This folder conteins the images of the maps generated in this project.
* The images are stored in PNG format.

## test
This folder conteins all scripts used to test the ALSRS system.

## scripts
This folder conteins all scripts used to generate the ALSRS system.
